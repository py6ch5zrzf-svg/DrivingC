# Driving C — категория C (v1.4)

PWA-приложение для инструктора по вождению категории C.

## Файлы для размещения
Загрузите в корень сайта **именно с такими именами**:
- `index.html`
- `manifest.json`
- `sw.js`
- `README.md`
- `icon-180.png`
- `icon-192.png`
- `icon-512.png`

Дополнительно в архиве есть `SV-01-26_students.csv` — готовый список из 30 учеников для нового импорта CSV.

## Что нового в v1.4
- расписание на 5–9 октября 2026 автоматически добавляется один раз при запуске обновлённого приложения;
- записи добавляются только если соответствующее время ещё свободно;
- «Мосеев Родион» используется в исправленном написании.

## Что нового в v1.3
- добавлен импорт расписания из CSV без удаления существующих занятий;
- новые занятия сопоставляются с учениками по ФИО; при небольшой опечатке в фамилии и совпадающем имени используется существующий ученик;
- исправленное имя из CSV может обновить фамилию ученика, сохраняя отчество;
- конфликты по времени и повторы при импорте пропускаются и показываются в результате.

## Что нового в v1.2
- добавлено редактирование данных ученика без удаления его истории занятий;
- добавлены отдельные иконки PWA для iPhone и других устройств;
- версия приложения, manifest и Service Worker приведены к v1.2;
- обновлён кэш офлайн-режима для корректного получения новой версии.

## Что исправлено ранее в v1.1
- исправлен выбор учеников: завершившие не предлагаются для новой записи, но остаются в журнале;
- исправлены идентификаторы скопированных занятий (раньше копии могли не редактироваться/не удаляться);
- копирование недели теперь не создаёт пересечения по времени;
- импорт JSON проверяется и нормализуется;
- добавлен импорт учеников из CSV;
- настройки названия и категории отражаются в интерфейсе;
- рабочее время теперь используется для предупреждения при записи вне диапазона;
- улучшен экспорт `.ics` и печать;
- Service Worker обновлён, чтобы приложение не застревало на старом `index.html`.

## Импорт учеников CSV
Поддерживаются колонки:
`ФИО;Телефон;Статус;План;Заметки`

Можно использовать и файл с одной колонкой ФИО.

## Резервная копия
Раздел **Данные** → **Экспорт JSON**. Для восстановления — **Импорт JSON**.

## Напоминания
Поле напоминания сейчас хранится как отметка в карточке занятия. Оно **не создаёт фоновое системное уведомление iPhone**.

## Установка на iPhone
Открыть сайт в Safari → **Поделиться** → **На экран «Домой»** → **Добавить**.

Данные сохраняются локально в браузере устройства. Рекомендуется регулярно делать резервную копию JSON.
