# Driving C — категория C

PWA-приложение для инструктора по вождению категории C.

## Структура
- Главная
- Расписание по неделям и просмотр дня
- Запись/редактирование/удаление вождения
- Проверка пересечений по времени
- Ученики: телефон, статус, план и факт часов
- Журнал
- Отчёты
- JSON резервная копия
- CSV журнал
- экспорт календаря `.ics`
- локальное хранение данных
- офлайн-кэш через Service Worker

## Установка на iPhone
Открыть сайт в Safari → Поделиться → На экран «Домой» → Добавить.
